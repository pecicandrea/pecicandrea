## CallScan

CallScan is one of my current projects. It's a customer support application where agents can register, upload their call recordings and review their previous calls.

The application transcribes the recording and provides a summary, category, sentiment, priority and recommended actions.

I built it using Python, FastAPI, PostgreSQL, SQLAlchemy, WhisperX, OpenAI and React.

CallScan: https://github.com/pecicandrea/callscan
